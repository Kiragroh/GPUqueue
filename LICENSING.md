# Licensing status

The project-wide license is awaiting the repository owner's selection. Public
visibility alone does not grant a general license to reuse or redistribute the
project's original source. An MIT license has been proposed to the owner.

Third-party components keep their own licenses. In particular, the generated
Archify viewer and embedded font retain the notices described in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
