Share the GPU. Keep the queue visible.

A Windows-first reference implementation for applications sharing one local GPU: an Ollama-compatible front door, managed CUDA command jobs, durable results and a desktop tray.

Explore the architectureSource & documentationFollow a request

Two paths, one admission policy

  • Applications submit inference to GPUqueue; admitted work goes to Ollama, and stored response bytes return to the caller.
  • A local command client obtains a lease and owns its CUDA process tree. The HTTP broker does not execute submitted commands.
  • The tray and web dashboard show status. A separate watchdog restarts a missing coordinator after user logon.

A starting point for development

Only integrated applications participate. Memory budgets are estimates, and uncertain cleanup stays blocked. This is a single-user Windows prototype, with no benchmark claim or cluster support.
